# 🚀 Easy CRM — Складской учет, продажи и аналитика

**Easy CRM** — это высокопроизводительное, специализированное программное обеспечение для розничных магазинов мобильных аксессуаров, электроники и сервисных центров. Система совмещает рабочее место кассира (POS), управление складом и товарной номенклатурой, глубокую аналитику дефицита и закупок, а также мобильный клиент для владельца бизнеса.

---

## 🌟 Основные возможности

### 🛒 Терминал кассира (POS)
* **Мгновенный поиск и сканирование:** работа со штрихкодами, артикулами и QR-кодами без задержек.
* **Управление продажами:** скидки, несколько способов оплаты (наличные, банковская карта/терминал, перевод, смешанная оплата Mix).
* **Сервисные услуги и расходы:** учет доп. услуг (поклейка стекол, ксерокопия, настройка) и операционных расходов из кассы.
* **Кассовые смены:** открытие и закрытие смен, сверка наличных и безналичных платежей, Z-отчеты.
* **Печать чеков и термоэтикеток:** прямая печать этикеток со штрихкодом (ESC/POS, Xprinter, термопринтеры).

### 📦 Склад и номенклатура
* **Каталог товаров:** артикулы, наименования, суффиксы, бренды, модели устройств, поставщики, себестоимость и цены продажи.
* **Умная инвентаризация и ревизия:** сканирование фактических остатков, фиксация расхождений и списаний.
* **Массовый импорт и экспорт:** быстрая загрузка товарных накладных через Excel/CSV.

### 📊 Центр закупок и тепловая матрица дефицита чехлов
* **Тепловая матрица спроса (Heatmap):** визуальная сетка моделей телефонов (iPhone, Samsung, Redmi и др.) против типов чехлов (Silicone, Leather, Clear, Armor) с цветовой индикацией оборачиваемости и маржинальности.
* **Автоматический расчет рекомендаций к закупу:** выявление позиций с критическим остатком и высоким темпом продаж.
* **Экспорт закупочных листов:** мгновенное формирование списков заказа для поставщиков в один клик.

### 📈 Бизнес-аналитика и отчеты
* **Интерактивные дашборды (ApexCharts):** графики маржинальности, выручки по дням, динамики продаж.
* **ABC-анализ категорий:** автоматическое ранжирование товарных групп по вкладу в прибыль.
* **Контроль залежавшихся товаров:** мониторинг позиций без движения более 30/60/90 дней.

## 🛠️ Архитектура и стек технологий

* **Backend:** Python 3, Flask, Werkzeug, Psycopg2 (PostgreSQL).
* **Frontend:** HTML5, CSS3 (современная темная тема Glassmorphism / Tabler UI), Vanilla JS.
* **Библиотеки визуализации:** ApexCharts (офлайн бандл), Chart.js, JsBarcode, QRCode.
* **База данных:** PostgreSQL 16 (высокая надежность транзакций, ACID, индексы для суб-миллисекундного отклика).
* **Автономность:** полностью автономная сборка в единый исполняемый файл `.exe` через PyInstaller (работает без необходимости установки Python на кассовом месте).
* **Мобильный клиент:** сопутствующее Android-приложение для владельца с синхронизацией в реальном времени.

## 🚀 Установка и запуск (для разработки)

### 1. Клонирование репозитория
```bash
git clone https://github.com/multizero88/easy-crm.git
cd easy-crm
```

### 2. Настройка виртуального окружения
```bash
python -m venv venv
# Активация окружения (Windows):
venv\Scripts\activate
# Установка зависимостей:
pip install flask psycopg2-binary reportlab
```

### 3. Запуск приложения
```bash
python app.py
```
После запуска интерфейс будет доступен в браузере по адресу: `http://localhost:5000`

---

## 📦 Сборка автономного исполняемого файла (.exe)

Сборка осуществляется с помощью скрипта `build.py`, который автоматически инкрементирует версию, упаковывает шаблоны, стили и библиотеки в один бинарный файл:

```bash
python build.py
```
Готовый `.exe` файл будет сохранен в папке `dist/easy-crm.exe`.
