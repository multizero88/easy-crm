Настройки системы и бэкапы

Инструкция по настройке

  1. Перейдите в Google Cloud Console.
  2. Создайте новый проект и включите Google Drive API в разделе «APIs & Services».
  3. В разделе «OAuth consent screen» выберите тип «External», укажите имя приложения и добавьте область действия (scope): .../auth/drive.file.
  4. В разделе «Credentials» создайте учетные данные типа «OAuth client ID» (тип приложения: «Web application»).
  5. Добавьте следующий адрес в поле «Authorized redirect URIs»:
    http://localhost:5000/api/gdrive/oauth-callback
  6. Скопируйте Client ID и Client Secret и вставьте их в форму справа.
  7. Раз в час система будет автоматически создавать резервную копию базы данных SQLite в папку «backup data» на вашем Google Диске при активном подключении.
